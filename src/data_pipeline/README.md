# Подготовка данных

- `llis_scraper.py` загружает NASA LLIS, очищает HTML и сохраняет сырой ответ в `data/raw/`, а нормализованный набор — в `data/processed/`.
- `build_chunks.py` делит уроки на секционные чанки, удаляет дубли и записывает `data/processed/llis_chunks.jsonl`.
- `rag_loader.py` загружает уроки и чанки как словари или объекты LangChain `Document`.

Запуск из корня: `python -m src.data_pipeline.llis_scraper`, затем `python -m src.data_pipeline.build_chunks`.

## Что происходит с данными

Скрейпер сохраняет ответ API для повторной обработки, преобразует HTML в Markdown, выделяет секции урока и собирает метаданные: номер, название, дату, центр NASA, программу и ссылку. Пустые записи и текстовые заглушки отбрасываются. Результат — набор уроков, пригодный для дальнейшего поиска.

Чанкер читает этот набор и делит каждую секцию отдельно. Длинный текст разбивается с перекрытием; к фрагментам добавляется контекст урока. Проверка токенов защищает от обрезания текста моделью BGE. Совпадающие фрагменты объединяются, при этом метаданные сохраняют ссылки на все соответствующие уроки.

`rag_loader.py` служит интерфейсом чтения этих файлов для остальных модулей: индексации не нужно самостоятельно разбирать JSONL. При необходимости загрузчик может вернуть целые уроки или отдельные секции.

## Входы, результаты и запуск

Вход скрейпера — NASA API либо сохранённый `data/raw/llis_raw.json`. Его результат `data/processed/llis_full.json` становится входом чанкера, который создаёт `data/processed/llis_chunks.jsonl`. В самой папке `data_pipeline` хранятся только Python-модули и документация.

Повторная очистка без скачивания: `python -m src.data_pipeline.llis_scraper --from-raw data/raw/llis_raw.json`. Проверка загрузчика: `python -m src.data_pipeline.rag_loader`. Скрейпер и чанкер перезаписывают свои выходные файлы; для чанкера можно указать собственные вход и выход позиционными аргументами. Для первого получения токенизатора может потребоваться сеть; затем используется кэш в `.fastembed_cache/`.
