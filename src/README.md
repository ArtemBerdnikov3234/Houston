# Исходный код

Пакет `src` содержит исполняемый код проекта. Общие пути к каталогам данных и кэша определены в `settings.py`, поэтому модули можно запускать из корня репозитория через `python -m`.

- `data_pipeline/` — получение, очистка, загрузка и чанкинг NASA LLIS.
- `retrieval/` — конфигурация Qdrant и загрузка векторного индекса.
- `evaluation/` — создание Gold Set и измерение качества поиска.
- `tools/` — вспомогательные проверки для разработчика.

## Как взаимодействуют модули

Сначала `data_pipeline` получает уроки NASA и готовит текстовые фрагменты. Затем `retrieval` вычисляет векторы и записывает их в Qdrant. После индексации `evaluation` отправляет эталонные вопросы в поиск и сравнивает выдачу с известными ответами. `tools` помогает отдельно проверить состав и качество исходного набора.

В этой директории хранится код, а создаваемые JSON, JSONL и отчёты находятся в соседней `data/`. `settings.py` вычисляет абсолютные пути относительно корня проекта и создаёт необходимые каталоги данных. Файлы `__init__.py` обозначают Python-пакеты и позволяют использовать импорты между модулями.

Все команды из документации выполняются из корня репозитория в активированном окружении с установленными зависимостями. Например, `python -m src.tools.inspect_dataset` запускает проверку данных. Подробности каждого этапа описаны в README соответствующей папки.
