# Данные проекта

- `raw/` — временные ответы NASA API; содержимое не коммитится, кроме файла `.gitkeep`.
- `processed/` — очищенные уроки `llis_full.json` и готовые к индексации чанки `llis_chunks.jsonl`.
- `benchmarks/` — основной и усложнённый Gold Set, включая удобные для просмотра CSV и Markdown.
- `evaluation/` — сохранённые метрики последних прогонов ретривера.

Большие обработанные файлы сейчас хранятся в Git, чтобы проект запускался без повторного скачивания и подготовки данных.

## Жизненный цикл файлов

Ответ NASA API попадает в `raw/`, после очистки уроки записываются в `processed/llis_full.json`. Чанкер создаёт рядом `llis_chunks.jsonl`, который читает индексатор. Генераторы эталонных вопросов используют уроки и чанки для проверки бенчмарков, а оценка поиска записывает метрики в `evaluation/`.

Данные отделены от исходного кода, чтобы можно было просматривать результаты этапов и повторно запускать отдельные операции. Подробности содержимого есть в README каждой вложенной папки. Кэш моделей и физическое хранилище Qdrant расположены отдельно в корне проекта и исключены из Git.

Генераторы обычно перезаписывают стандартные выходные файлы. При изменении уроков необходимо заново подготовить чанки, проверить Gold Set и обновить индекс перед новой оценкой. Сохранённые метрики описывают предыдущий прогон и сами по себе не подтверждают состояние текущего сервера.
