# Инструменты разработчика

`inspect_dataset.py` выводит размер датасета, распределение по центрам NASA, заполненность секций и статистику длины текстов. По умолчанию анализирует самый свежий `llis_*.json` из `data/processed/`.

Запуск: `python -m src.tools.inspect_dataset`.

## Что хранится и как используется

Здесь находятся вспомогательные инструменты проверки, которые не создают векторный индекс и не участвуют в выдаче результатов поиска. Сейчас это один скрипт `inspect_dataset.py` и файл `__init__.py`, обозначающий Python-пакет.

Скрипт читает подготовленные уроки, считает записи и уникальные ID, показывает основные центры NASA, долю заполненных секций и распределение длины текстов. В конце выводится фрагмент первого документа. Это помогает заметить пустые разделы или неожиданное изменение объёма после повторного сбора данных.

Для конкретного файла: `python -m src.tools.inspect_dataset data/processed/llis_full.json`. Вход должен иметь структуру набора уроков; файлы Gold Set и результаты оценки для этой команды не предназначены. Скрипт выводит информацию в терминал, не изменяет данные и не требует запущенного Qdrant.
