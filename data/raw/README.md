# Исходные ответы NASA API

Здесь хранится `llis_raw.json` — ответ API до очистки. Его создаёт `src.data_pipeline.llis_scraper` при скачивании базы. Файл полезен для повторной обработки: можно менять очистку HTML и выделение секций без нового запроса к NASA.

Команда из корня: `python -m src.data_pipeline.llis_scraper --from-raw data/raw/llis_raw.json`. Результат очистки записывается в `data/processed/`, исходный дамп служит входом.

JSON-файлы этой папки исключены из Git. После клонирования дампа может не быть; его создаёт обычный запуск скрейпера. README и `.gitkeep` сохраняют описание и структуру каталога в репозитории.
