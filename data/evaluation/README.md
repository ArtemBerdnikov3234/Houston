# Результаты оценки поиска

В этой папке сохраняются JSON-отчёты модуля `src.evaluation.check_qdrant`. `retrieval_eval.json` относится к основному Gold Set, `retrieval_eval_hard.json` — к усложнённому.

Отчёты содержат результаты dense, sparse и hybrid-поиска: долю найденных уроков и цитат, MRR, пропущенные вопросы, задержку и метрики по группам. Они нужны для сравнения настроек и выявления случаев, где поиск не находит подтверждающий фрагмент.

Обычный запуск оценки перезаписывает стандартный отчёт. Для отдельного прогона используйте `--out data/evaluation/my_run.json`. При сравнении дополнительно фиксируйте версию данных и настройки моделей: существующие отчёты не являются полным журналом конфигурации эксперимента. Просмотр сохранённых JSON не требует работающей базы, а получение новых метрик требует Qdrant и индекса.
