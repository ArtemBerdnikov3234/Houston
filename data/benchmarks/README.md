# Эталонные вопросы для оценки поиска

Здесь хранятся два набора по 50 вопросов с эталонными ответами, цитатами и ссылками на уроки. Они позволяют оценивать изменения поиска на фиксированных примерах.

- `gold_set_50.json` — основной набор для автоматической оценки.
- `gold_set_50.csv` — тот же набор для просмотра в табличном редакторе.
- `gold_set_50.md` — читаемый отчёт с вопросами и ответами.
- `gold_set_hard.json` — усложнённый набор с перефразированными вопросами, фильтрами и несколькими релевантными уроками в части примеров.

Файлы создают модули `src.evaluation.generate_gold_set` и `src.evaluation.generate_gold_set_hard`. Исходные формулировки находятся в коде генераторов; правки только в экспортированных файлах будут потеряны при повторной генерации. Проверка цитат использует файлы из `data/processed/`.

Для оценки Hard-набора: `python -m src.evaluation.check_qdrant --eval-only --gold data/benchmarks/gold_set_hard.json`. Сервер Qdrant должен быть запущен и проиндексирован.
